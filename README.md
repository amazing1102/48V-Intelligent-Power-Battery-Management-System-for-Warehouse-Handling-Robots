# BMS-48Pro

面向仓储搬运机器人的 13S LiFePO4 动力电池管理系统原型。项目需求见仓库根目录的《BMS-48Pro_仓储搬运机器人48V智能动力电池管理系统_开发需求文档.md》。

## 当前状态

本目录是新建的软件工程和可主机编译的固件核心，不是可直接烧录的 MCU 工程。根目录 `BQ76940/` 中的资料和厂商裸机例程作为只读参考；例程默认面向 15 串及 STM32F103RBT6，不能直接作为本项目配置。

硬件方案尚需确认：实际 MCU 料号、BQ76940 板卡采样线映射、BQ76200/功率级是否在基础板上、电流分流器阻值与极性、NTC 型号，以及电芯和负载保护边界。上述信息确认前，功率输出默认应保持关闭，保护阈值不作为定值使用。

## 目录

- `firmware/`: MCU 固件源码
- `firmware/include/bms/`: 平台无关的 BMS 类型和模块接口
- `firmware/src/`: 模块实现
- `firmware/board/`: 板级引脚、硬件映射和平台适配
- `docs/`: 项目内开发记录与验证清单
- `tests/`: 不依赖硬件的核心逻辑测试

## 目标架构

固件按采集、保护决策、功率控制、通信和日志分层。BQ76940 硬件保护承担快速故障底线；软件状态机只在采样有效且保护允许时提出功率动作。FreeRTOS、STM32 HAL/标准外设库及器件驱动接入前，先确认工程目标芯片和板卡接口。

## 建议开发顺序

1. 对照原理图确认硬件版本、MCU、13S VC 引脚映射和 MOS 驱动链路。
2. 建立安全启动与器件通信自检，验证失败时维持功率关闭。
3. 移植 BQ76940 驱动并用模拟电芯验证电压、温度、电流和硬件保护状态。
4. 加入任务调度、保护状态机和唯一功率控制入口。
5. 按项目协议重做 CAN 标准帧接口，并增加日志、IAP 和上位机联调。

所有阈值、延时、分流器换算和电芯映射都应由已确认的硬件参数及测试结果决定，不沿用厂商演示代码中的常量。

## 当前实现与构建

目前已实现平台无关的保护决策、预充/功率状态机和 CAN 命令帧校验。未配置有效阈值、AFE 通信无效、测量无效或过期时，决策均禁止充放电。安全阈值没有内置默认值。

使用 CMake 和 C 编译器可在主机上运行核心测试：

```sh
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build
ctest --test-dir build --output-on-failure
```

当前主机环境也可用 GCC 直接编译 `firmware/src/*.c` 与 `tests/test_bms_core.c`。STM32CubeMX/Keil 工程将在确认实际 MCU、时钟、引脚和硬件接口后生成；不要将主机测试可执行文件用于电池系统。
